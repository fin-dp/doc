The report module allows querying financial result e.g. balance for an account.

Example

const report = require('dfp/report');

const balance = report.balance('account1', {currency: 'USD'});

Results

Balance return just a single close balance that wrapped with decimal type for better usability

Trial returns an object with the following properties

  • open (decimal) - open balance
  • close (decimal) - closing balance
  • debit (decimal)
  • credit (decimal)
  • debitCount (int) - count of the debit entries
  • creditCount (int) - count of the credit entries

Methods

Balance​

Returns balance for an account with parameters


const balance = report.balance('account1', {
    currency: 'USD',
    fromTimestamp: '2025-01-01', // optional
    toTimestamp: '2025-12-15', // optinal
    source1: 'bank1', // optional
});

// result will look like
result = decimal(100)

TrialBalance​

Returns open, close balance and debit with credit


const balance = report.balance('account1', {
    currency: 'USD',
    fromTimestamp: '2025-01-01', // optional
    toTimestamp: '2025-12-15', // optinal
    source1: 'bank1', // optional
});

// result will look like
// close = open + debit - credit
balance.open   // 20
balance.debit  // 500
balance.credit // 420
balance.close  // 100

BalanceGroup​

Returns balance for an account with grouping by source


const balances = report.balanceGroup('account1', {
    currency: 'USD',
    groupBySource: 1,
    fromTimestamp: '2025-01-01', // optional
    toTimestamp: '2025-12-15', // optinal
    source2: 'partner', // optional
});

for (let v in balances) {
    if (balances[v].gt(0)) {
        log.info('bank: ' + v + ' balance = ' + balances[v])
    }
}
// output
// bank: bank1 balance = 100
// bank: bank2 balance = 200.55

AccountEntries​

Returns the basic entries for a given filter


const entries = report.accountEntries('account1', {
    currency: 'USD',
    fromTimestamp: '2025-01-01', // optional
    toTimestamp: '2025-12-15', // optinal
    source2: 'partner', // optional
    limit: 1000, // optinal, returns limited amount of the entreis 
});
