Report

Overview​

The dfp/report module provides comprehensive accounting reporting functionality for JavaScript environments. It enables querying account balances, turnovers, entries, and currency information with flexible filtering and grouping options.

Module Import​

const report = require('dfp/report');

Core Concepts​

Account Identification​

Accounts can be referenced by:

  • Account code (string): "1001", "CASH"
  • Account ID (integer): 123

Source Identification​

Sources can be specified using:

  • Source code (string): "DEP001", "CUSTOMER-XYZ"
  • Source ID (integer): 456

Timestamps​

All timestamp parameters accept:

  • JavaScript Date objects
  • ISO 8601 strings ("2023-01-01T00:00:00Z")
  • Unix timestamps (milliseconds)

API Functions​

Balance Queries​

balance(account, [options]) → Decimal​

Returns the closing balance for an account.

Parameters:

  • account (string|number): Account code or ID
  • options (object, optional): Query options
    • timestamp or toTimestamp: Cut-off date/time
    • from or fromTimestamp: Start date/time for period
    • currency: Currency code
    • source1, source2, source3: Source filters

Returns: Decimal - Closing balance amount

Example:

// Get current balance
const balance = report.balance("1001");

// Get balance as of specific date
const balance = report.balance("1001", {
    timestamp: "2023-12-31",
    currency: "USD"
});

trialBalance(account, [options]) → Object​

Returns detailed turnover information including opening balance, debit/credit totals, and closing balance.

Returns:

{
    open: Decimal,      // Opening balance
    debit: Decimal,     // Total debit turnover
    debitCount: Number, // Number of debit entries
    credit: Decimal,    // Total credit turnover
    creditCount: Number,// Number of credit entries
    close: Decimal      // Closing balance
}

Example:

const result = report.trialBalance("CASH", {
    from: "2023-01-01",
    to: "2023-12-31"
});
console.log(`Opening: ${result.open}`);
console.log(`Closing: ${result.close}`);

Grouped Queries​

trialGroupBySources(account, options) → Array​

Groups results by specified source dimensions.

Options additions:

  • groupBySources: Array of source indices to group by (e.g., [1, 2])

Returns: Array of result objects with source codes included

Example:

const results = report.trialGroupBySources("CASH", {
    from: "2023-01-01",
    to: "2023-12-31",
    groupBySources: [1, 2]
});

results.forEach(item => {
    console.log(`Source1: ${item.sources[0]}, Source2: ${item.sources[1]}`);
    console.log(`Balance: ${item.close}`);
});

balanceGroup(account, options) → Object​

Groups balance by a single source, returning a map of source codes to balances.

Options additions:

  • groupBySource: Source index to group by

Returns: Object with source codes as keys and Decimal balances as values

Example:

const balances = report.balanceGroup("CASH", {
    timestamp: "2023-12-31",
    groupBySource: 1
});

for (const [source, balance] of Object.entries(balances)) {
    console.log(`${source}: ${balance}`);
}

trialGroup(account, options) → Object​

Similar to balanceGroup but returns full trial balance objects per source.

Returns: Object with source codes as keys and full result objects as values

Example:

const results = report.trialGroup("CASH", {
    from: "2023-01-01",
    to: "2023-12-31",
    groupBySource: 1
});

for (const [source, data] of Object.entries(results)) {
    console.log(`${source}: Open=${data.open}, Close=${data.close}`);
}

Entry Queries​

accountEntries(account, [options]) → Array​

Returns detailed entry listings.

Options:

  • fromTimestamp: Start date
  • toTimestamp: End date
  • currency: Currency filter
  • limit: Maximum number of entries
  • source1, source2, source3: Source filters

Returns: Array of entry objects

Entry Object Structure:

{
    id: Number,                 // Entry ID
    timestamp: Date,             // Entry timestamp
    amount: Decimal,             // Entry amount
    currency: String,            // Currency code
    isDebit: Boolean,            // True if debit entry relative to queried account
    account: String,             // Account code (debit or credit side)
    sources: [String],          // Source codes for the relevant side
    debitAccount: String,        // Debit account code
    debitSources: [String],     // Debit side source codes
    creditAccount: String,       // Credit account code
    creditSources: [String],    // Credit side source codes
    documentId: String,          // Source document identifier
    documentRowNumber: Number,   // Row number in source document
    references: [{               // Reference links
        code: String,
        groupCode: String
    }]
}

Example:

const entries = report.accountEntries("CASH", {
    fromTimestamp: "2023-01-01",
    toTimestamp: "2023-01-31",
    limit: 100,
    source1: "DEP001"
});

entries.forEach(entry => {
    console.log(`${entry.timestamp}: ${entry.amount} ${entry.currency}`);
    console.log(`  Debit: ${entry.debitAccount}, Credit: ${entry.creditAccount}`);
});

Currency Queries​

usedCurrencies(account, [options]) → [String]​

Returns list of currencies used in transactions for the specified account and period.

Example:

const currencies = report.usedCurrencies("CASH", {
    from: "2023-01-01",
    to: "2023-12-31"
});
console.log("Currencies used:", currencies);

Sorting and Pagination​

Grouped results support sorting and pagination:

Sort Options:

  • sortBy: Field to sort by ("balanceClose", "balanceOpen", "debit", "credit")
  • sortDirection: "asc" or "desc"

Pagination:

  • limit: Maximum number of results
  • offset: Number of results to skip

Example:

const results = report.trialGroupBySources("CASH", {
    from: "2023-01-01",
    to: "2023-12-31",
    groupBySources: [1],
    sortBy: "balanceClose",
    sortDirection: "desc",
    limit: 10,
    offset: 0
});

Error Handling​

All functions may throw errors for:

  • Invalid account references
  • Unknown currency codes
  • Missing source codes
  • Invalid source indices for the account
  • Database connectivity issues

Example with error handling:

try {
    const balance = report.balance("INVALID_ACCOUNT");
} catch (error) {
    console.error("Balance query failed:", error.message);
}

Decimal Type​

The module uses a custom Decimal type for all monetary values. Decimal objects support:

  • Arithmetic operations: add(), sub(), mul(), div()
  • Comparison: equals(), greaterThan(), lessThan()
  • String conversion: toString()

Example:

const balance = report.balance("CASH");
console.log(balance.toString()); // "1234.56"
const doubled = balance.mul(2); // 2469.12
