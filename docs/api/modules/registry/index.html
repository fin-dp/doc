Registry

Overview​

The Registry module provides a JavaScript interface for managing and accessing registry entries in the system. It supports CRUD operations, parameter management, and search capabilities for registry items with time-based validity.

Module Loading​

const registry = require('dfp/registry');

Core Concepts​

Registry Object Structure​

Registry objects returned by various methods have the following structure:

{
  code: string,           // Unique identifier for the registry entry
  description: string,    // Human-readable description
  value: string,          // Primary value stored in the registry
  params: object          // Additional parameters as key-value pairs
}

Registry Types​

Registry entries are organized by type. Each registry type has a unique code defined in the system.

Validity Periods​

Registry entries can have time-based validity with valid_from and valid_till dates. When querying, you can specify a timestamp to get the value valid at that specific time.

Methods​

has(registryType, code, [timestamp])​

Checks if a registry entry exists for the given type and code at the specified time.

Parameters:

  • registryType (string): Registry type code
  • code (string): Registry entry code
  • timestamp (string|Date|number, optional): Point in time to check validity (defaults to current time)

Returns: boolean - true if entry exists and is valid at the specified time

Example:

const exists = registry.has('customer', 'Sample Tech Company');
const existedLastYear = registry.has('payment_method', 'USDT-EUR', '2022-01-01');

get(registryType, code, [timestamp])​

Retrieves the value of a registry entry.

Parameters:

  • registryType (string): Registry type code
  • code (string): Registry entry code
  • timestamp (string|Date|number, optional): Point in time to get the value (defaults to current time)

Returns: string|null - The registry value or exception if not found

Example:

const rate = registry.get('VALIDATOR', '25465347');
const historicalRate = registry.get('ACCOUNT', '12345', '2023-06-01');

list(registryType, [timestamp])​

Lists all registry entry codes for a given type.

Parameters:

  • registryType (string): Registry type code
  • timestamp (string|Date|number, optional): Point in time to filter valid entries (defaults to current time)

Returns: string[] - Array of registry entry codes

Example:

const allValidators = registry.list('VALIDATOR');
const activeAccounts = registry.list('ACCOUNT', new Date());

set(registryType, code, options)​

Creates (upsert) a registry entry.

Parameters:

  • registryType (string): Registry type code
  • code (string): Registry entry code
  • options (object, optional): Configuration object with the following properties:
    • value (string): The primary value to store
    • description (string): Description of the registry entry
    • nx (boolean): If true, only insert if entry doesn't exist (no update)
    • params (object): Additional parameters specific to the registry type

Returns: void

Examples:

// Simple value
registry.set('ACCOUNT', '12345', { value: 'qwerty' });

// With description
registry.set('ACCOUNT', 'EUR', { 
  value: 'Euro',
  description: 'European Union ACCOUNT'
});

// With typed parameters
registry.set('EXCHANGE_RATE', 'USD-EUR', {
  value: '0.85',
  params: {
    fromACCOUNT: 'USD',
    toACCOUNT: 'EUR',
    rate: '0.85'
  }
});

// Insert only if not exists
registry.set('ACCOUNT', 'GBP', { 
  value: 'British Pound',
  nx: true 
});

update(registryType, code, options)​

Updates a registry entry. Supporting partially update only new provided parameters and options.

Parameters:

  • registryType (string): Registry type code
  • code (string): Registry entry code
  • options (object, optional): Configuration object with the following properties:
    • value (string): The primary value to store
    • description (string): Description of the registry entry
    • params (object): Additional parameters specific to the registry type

Returns: void

Examples:

// Simple set entire registry
registry.set('test_params', 'test4', {
  value: 'v1',
  description: 'test descr',
  params: {
    s_text: 'asdasdasd',
    s_date: '2026-04-01',
    s_select: 'val1',
    s_currency: 'ETH',
    s_registry: 'company one',
    s_text2: 'text_val2'
  }})

// partially update few params
registry.update('test_params', 'test1', {
    value: 'v2', 
    description: 'test description', 
    params: {
      s_date: '2026-04-02',
      s_select: 'val2',
      s_currency: 'BTC',
  }})

fetch(registryType, code, [timestamp])​

Retrieves a complete registry object including all parameters.

Parameters:

  • registryType (string): Registry type code
  • code (string): Registry entry code
  • timestamp (string|Date|number, optional): Point in time to get the entry (defaults to current time)

Returns: RegistryObject - Complete registry entry

Example:

const account = registry.fetch('ACCOUNT', '12345');
console.log(account.code);        // "12345"
console.log(account.description);  // "Main Checking Account"
console.log(account.value);        // "ACTIVE"
console.log(account.params);       // { ACCOUNT: "USD", branch: "NY" }

find(registryType, criteria)​

Searches for registry entries based on various criteria.

Parameters:

  • registryType (string): Registry type code
  • criteria (object): Search criteria with the following properties:
    • code (string): Exact match on code
    • description (string): Exact match on description
    • value (string): Exact match on value
    • q (string): Full-text search across all fields
    • params (object): Filter by parameter values
    • limit (number): Maximum number of results to return

Returns: RegistryObject[] - Array of matching registry entries

Examples:

// Search by code
const results = registry.find('ACCOUNT', { code: '123%' });

// Full-text search
const accounts = registry.find('ACCOUNT', { 
  q: 'checking savings' 
});

// Filter by parameters
const eurAccounts = registry.find('ACCOUNT', {
  params: { ACCOUNT: 'EUR' }
});

// Combined search with limit
const activeAccounts = registry.find('ACCOUNT', {
  value: 'ACTIVE',
  params: { type: 'checking' },
  limit: 10
});

Parameter Types​

When working with typed registry parameters, the following types are supported:

Currecny Type​

Parameters marked as currency will be linked to currency registry entries:

params: {
  currency: 'USD'  // Will be resolved to currency ID
}

Source Type​

Parameters marked as source link to source system entries:

params: {
  source: 'BANK_SYSTEM'  // Will be resolved to source ID
}

Registry Type​

Parameters marked as registry link to other registry entries:

params: {
  parentAccount: '12345'  // Will be resolved to registry ID
}

Basic Types​

Other parameter types (string, number, date, boolean) are stored directly:

params: {
  interestRate: '3.5',
  minBalance: 1000,
  allowOverdraft: true,
  openDate: '2023-01-01'
}

Error Handling​

The module throws JavaScript errors that should be handled with try-catch:

try {
  const value = registry.get('NONEXISTENT', 'CODE');
} catch (error) {
  console.error('Registry operation failed:', error.message);
  // Handle error appropriately
}

Common error scenarios:

  • Registry type not found
  • Registry entry not found
  • Invalid timestamp format
  • Missing required parameters
  • Referenced registry entries not found
  • Unsupported options parameters

Examples​

Complete Workflow Example​

// Create a new account type
registry.set('ACCOUNT_TYPE', 'SAVINGS', {
  description: 'Savings Account',
  value: 'ACTIVE',
  params: {
    minBalance: 100,
    interestRate: '2.5',
    currency: 'USD',
    allowOverdraft: false
  }
});

// Verify it exists
const exists = registry.has('ACCOUNT_TYPE', 'SAVINGS');
console.log('Account type exists:', exists);

// Search for savings accounts
const savingsTypes = registry.find('ACCOUNT_TYPE', {
  params: { allowOverdraft: false }
});

// Get full details
const savings = registry.fetch('ACCOUNT_TYPE', 'SAVINGS');
console.log('Savings account details:', savings);
